About This Tool

I built this after realizing I was spending more time managing spreadsheets than actually comparing tennis racquet specs. This site pulls everything into one place so you can search, filter, and sort by the specs that matter to you.

You can filter by racquet weight, swingweight, stiffness, beam width, head size, length, string pattern, and more. If you’ve ever searched “racket weight tennis,” “tennis racquet specs,” or “tennis racquet compare,” this should help streamline that process.

It works well as a tennis racquet finder if you’re trying to match an older frame or dig into racquet comparisons across brands. Everything’s filterable and exportable, with specs pulled from Tennis Warehouse and Tennis Express.

The goal is to make tennis racket specifications easy to work with — whether you're deep into gear or just looking for your next racquet. This used to be a spreadsheet, but I always wanted to make it a web tool.


So please enjoy. And please submit a feedback request form if something sucks.
